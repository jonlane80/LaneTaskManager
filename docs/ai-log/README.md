# AI Instruction Log

A record of significant instructions given to AI assistants while building this project, with a
summary of each response. One file per entry, named `NNNN-short-title.md` and numbered in order.

## Entry format

```markdown
# NNNN – Title

- **Date:** YYYY-MM-DD
- **Assistant:** tool / model
- **PR:** link, if any

## Instruction

> The prompt, verbatim.

## Response summary

What was done, key decisions, and anything left open.
```
